# Jayvee Hilario — Developer Portfolio

My personal portfolio: about me, skills, projects, and contact.
A single-page static site — no frameworks, no build step.

## Sections

- Hero — intro and quick links
- About — background, how I work, what I'm exploring
- Skills — languages, web, tools, currently exploring
- Projects — Trading-Agent, HydroReminder, and this site (linked to GitHub)
- Contact — email, GitHub, LinkedIn, plus a front-end message form

## Files

- `index.html` — the whole site
- `css/styles.css` — all styles
- `js/main.js` — nav, scroll animations, contact form validation

## Run locally

```bash
python -m http.server 8000
```

then open http://localhost:8000

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel) — just serve the repo root.
